# Rot13 for Bluesky

I'm tired of copypasting stuff on rot13.com. Here's a browser extension that adds ROT13 encode/decode to Bluesky.

## Features
- **Decode Rot13** option on the post's hamburger menu
- **Encode Rot13** button on the composer screen
- **Ignore links/mentions** toggle in the toolbar popup

## Install (development)

Install via Firefox/Chrome extension managers.
